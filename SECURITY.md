# Security

Follow the [ANS security policy](https://github.com/agentnameservice/governance/blob/main/SECURITY.md)
for vulnerability handling, response targets, and coordinated disclosure.

To report a vulnerability in this repository, use
[Report a vulnerability](https://github.com/agentnameservice/scoop-ans/security/advisories/new)
in its Security tab. Do not include vulnerability details or credentials in a
public issue, pull request, or discussion.

## Supported versions

This repository distributes the ANS CLI. Its supported releases follow the
[Go SDK security policy](https://github.com/agentnameservice/ans-sdk-go/blob/main/SECURITY.md).
Report vulnerabilities in the CLI itself to
[ans-sdk-go](https://github.com/agentnameservice/ans-sdk-go/security/advisories/new).
Use this repository's reporting link for problems in its package distribution.
