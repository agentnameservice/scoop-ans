# ANS Scoop bucket

This bucket distributes the [ANS CLI](https://github.com/agentnameservice/ans-sdk-go)
for Windows.

## Install

```powershell
scoop bucket add ans https://github.com/agentnameservice/scoop-ans
scoop install ans/ans-cli
```

See the [CLI documentation](https://github.com/agentnameservice/ans-sdk-go#cli-quickstart)
for configuration and usage. The [manifest](bucket/ans-cli.json) is generated by
the Go SDK release process.
