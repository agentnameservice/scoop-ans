# Contributing

Follow the [ANS contribution guide](https://github.com/agentnameservice/governance/blob/main/CONTRIBUTING.md)
and [governance](https://github.com/agentnameservice/governance/blob/main/GOVERNANCE.md).
They define DCO sign-off, pull request review, issue references, and disclosure
of AI assistance.

The [Code of Conduct](CODE_OF_CONDUCT.md) applies to all participation.
Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
The repository's [Maintainers](MAINTAINERS.md) handle reviews and releases.

## Package licensing

The license in a package manifest applies to that specific CLI release.
The release archive contains its license texts and notices. The
[Go SDK's licensing policy](https://github.com/agentnameservice/ans-sdk-go#license)
and release configuration determine the license metadata for new releases.
Do not change the licensing record of an already-published binary.

## Package updates

The [package manifest](bucket/ans-cli.json) is generated by the
[Go SDK release configuration](https://github.com/agentnameservice/ans-sdk-go/blob/main/.goreleaser.yaml).
Make changes to the CLI or its release generation in
[ans-sdk-go](https://github.com/agentnameservice/ans-sdk-go).
For changes to this repository's documentation, follow the contribution guide
above. Installation instructions are in [README.md](README.md).
